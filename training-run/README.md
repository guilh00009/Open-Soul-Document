# castform training run

Generated by the castform experiment wizard.

## Setup

```bash
uv venv
source .venv/bin/activate
uv pip install benchmax
```

## Run

```bash
python run.py
```

`run.py` opens a browser to sign you in on first run — no API key to manage.
For headless / CI, set `PLATFORM_API_KEY` ([app.castform.dev/account/api-keys](https://app.castform.dev/account/api-keys)) instead.

## Files

- `run.py` — training script

## Dataset

This template doesn't bundle a dataset. `run.py` reads `train_dataset.jsonl` and `eval_dataset.jsonl` from this folder — add them before running (one JSON object per line, each with your `prompt` and `ground_truth`).
